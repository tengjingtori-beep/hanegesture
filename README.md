# HaneGesture（はねジェスチャー）

ウェブカメラで読み取った**本物の手の動き**に合わせて、Minecraft（Java版）の一人称視点の手が**リアルタイムに動く**modです。
固定のアニメーションではありません。指1本ずつの曲がり具合、手首の傾きが、そのままゲーム内の手に伝わります。

AIアプリ「てジェスチャーAI v2」とセットで使います。

## しくみ

| 部品 | 役割 |
|---|---|
| てジェスチャーAI v2（ブラウザ） | カメラで手の関節21点を読み取り、骨格データを送る |
| このmod（Fabric） | データを受け取り、手のモデルとゲーム操作に変える |
| つなぎ方 | WebSocket（このmodがポート8765で待ち受け、アプリが接続する） |

## 対応バージョン

| 項目 | 内容 |
|---|---|
| Minecraft | **Java版 26.3** |
| modローダー | Fabric Loader 0.20.1以上 |
| 必要なもの | Fabric API |
| Java | 25 |

## ビルド方法（jarの作り方）

### 方法A: GitHubで自動ビルド（おすすめ）

1. このフォルダの中身を、GitHubの新しいリポジトリにアップロードする
2. 「Actions」タブで「Build HaneGesture」が自動で動く
3. 終わったら、結果（Artifacts）の `hanegesture-jar` をダウンロードする
4. 中の `hanegesture-1.0.0.jar` がmod本体

### 方法B: パソコンでビルド

```
gradle build
```
できたjarは `build/libs/hanegesture-1.0.0.jar` です。

## 使い方

| 手順 | やること |
|---|---|
| 1 | Fabric 26.3 のマイクラに、このmodと Fabric API を入れる（modsフォルダ） |
| 2 | マイクラを起動する（modが自動で待ち受けを開始します） |
| 3 | 「てジェスチャーAI v2」（hand_gesture_mod.html）をChromeで開き、「カメラを始める」 |
| 4 | アプリの「mod連携」で「接続する」を押す（アドレスは ws://localhost:8765 のまま） |
| 5 | ゲームに戻ると、一人称の手が自分の手と連動します |

## 操作対応表

| 本物の手の動き | ゲーム内の動き |
|---|---|
| 指を曲げる・伸ばす | 手モデルの指が同じだけ曲がる（15関節すべて） |
| 手首を傾ける | 手モデルが傾く |
| グーにする（握る） | 攻撃（左クリック長押し） |
| 親指と人差し指をつまむ | 使う／置く（右クリック長押し） |
| 手をカメラへ素早く突き出す | 攻撃ワンプッシュ＋手を振る |
| F8キー | 連動の ON／OFF 切り替え |

手をカメラから外すと、自動で通常の手に戻ります。

## 正直な注意点

- ゲーム内の手は「関節で動く立体モデル」です。写真のような本物の手の見た目にはなりません（マイクラの描画の限界です）。代わりに、動きは本物そのままです。
- 手に持っている道具は、手モデル表示中は見えなくなります（攻撃・使用の操作は効きます）。また今の版では、連動中は読み取っている方の手だけが表示され、もう片方の手は消えます。
- このmodは、はねの環境で本物のマイクラ26.3のファイルと照らし合わせてコンパイル確認済みです（通信・角度計算・操作判定の単体テストも合格）。ただしゲーム内での実際の表示は実機未確認です。おかしい所があれば教えてください。
- マルチプレイでも使えます（自分の画面と入力だけの仕組み）。サーバーのルールは守ってください。
